# Nordic SCADA - Система диспетчеризации вентиляции

## Описание
SCADA-система с дизайном в стиле Nordic для управления системами вентиляции и кондиционирования.

## Возможности

### Роли пользователей
- **Оператор**: просмотр графиков, мнемосхем, журнала аварий
- **Администратор**: полный доступ + настройка устройств, редактирование мнемосхем, управление переменными

### Функционал

#### 1. Устройства
- Добавление устройств по TCP/IP или MODBUS RTU
- Загрузка карты переменных (CSV/MAP)
- Индикация состояния: РАБОТА / СТОП / АВАРИЯ
- Двойной клик открывает мнемосхему устройства

#### 2. Мнемосхемы
- Библиотека SVG элементов (вентиляторы, заслонки, нагреватели, фильтры, датчики)
- Перетаскивание элементов из библиотеки
- Поворот элементов на 45°
- Привязка переменных к элементам
- Сетка с изменяемым масштабом
- Масштабирование и перемещение поля мышью
- Сохранение в JSON

#### 3. Настройки (Администратор)
- Изменение пароля администратора (стартовый: 333)
- Настройка пути к файлу секретов
- Добавление модулей с настройкой видимости для оператора

#### 4. Аварии
- Просмотр актуальных и архивных аварий
- Фильтрация по устройству
- Рекомендации по устранению

#### 5. I/O Монитор (Администратор)
- Просмотр карты переменных устройства
- Изменение записываемых переменных

#### 6. Графики
- Отображение динамики переменных
- Множественные графики с разными цветами
- Обновление в реальном времени

## Запуск

```bash
cd nordic-scada
python3 -m http.server 8080
```

Откройте в браузере: http://localhost:8080

## Структура проекта
```
nordic-scada/
├── index.html          # Главный HTML файл
├── css/
│   └── style.css       # Стили в Nordic дизайне
├── js/
```

## Вход в систему
- **Оператор**: выбрать роль "Оператор", нажать "Войти" (пароль не требуется)
- **Администратор**: выбрать роль "Администратор", пароль: `333`

## Технические особенности
- Хранение данных в localStorage браузера
- Drag-and-drop для элементов мнемосхемы
- Canvas для отрисовки графиков
- Адаптивный интерфейс
- Минималистичный Nordic дизайн
